# ZYON - Bot de WhatsApp con IA peruana 🤖

Bot de WhatsApp basado en Baileys, personalizado con inteligencia artificial peruana.

## Características
- Respuestas automáticas usando IA.
- Desplegable en Render (gratuito).
- Persistencia de sesión.

## Despliegue en Render
1. Haz fork de este repositorio.
2. Crea un Web Service en Render y conecta tu repositorio.
3. Configura las variables de entorno (ver `render.yaml`).
4. Escanea el QR en `https://tu-bot.onrender.com/qr`.
